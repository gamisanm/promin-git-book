# Возврат VAT по фактурам

## **Категории товаров, подлежащих возврату VAT**

* Автомобильные аксессуары
* Электронные аксессуары (телефон, планшет, ноутбук)
* Детали велосипеда
* Детали автомобиля
* Детское кресло
* Автомойки/чистка автомобиля
* Масла, смазки и другие жидкости для авто
* Покупка топлива

## **Топливо**

* **Топливные карты AMIC и E100**: возврат VAT осуществляется 1 раз в месяц - до 10 числа, за предыдущий.&#x20;
* Подробности об использовании: [t.me/Promin\_News/450](https://t.me/Promin_News/450).
* Для остальных заправок возможно получение фактуры и возврат VAT по ним (BP, Shell, Orlen и т.п.):
* В фактуре обязательно должен быть указан номер автомобиля.
* На автомобиль, указанный в фактуре, должен быть оформлен договор аренды (Umowa Wynajmu).
*   При просьбе о выставлении фактуры нужно указывать данные:

    **LET\&BE SPÓŁKA Z OGRANICZONĄ ODPOWIEDZIALNOŚCIĄ**

    **NIP** - 8241818172

    **Województwo** - MAZOWIECKIE

    **Miejscowość** - Węgrów

    **Adres** - ul. Marsz. J. Piłsudskiego 19A, 07-100
* Должен быть подписан договор VAT.&#x20;

<mark style="color:red;">**Если хотя бы одно из этих условий не будет выполнено, возврат VAT невозможен.**</mark>

**Варианты выплаты возврата VAT**

* **В течении 5 рабочих дней**
* **Крупные покупки** (от 2000 zł): возврат в течение 14 дней(то есть на 15й день с момента подачи фактуры).

! Возврат VAT возможен только при наличии заработка по договору Umowa Wynajmu. Выплата будет произведена с назначением „Zwrot kosztów”, поэтому дополнительно оплачивать налог Ryczałt не требуется.\
Как только появится доход по данному типу договора — возврат VAT будет автоматически произведён.\
! Возврат VAT возможен только при установленном расчете на номер счета, если стоит выплата наличными, то пока человек не сменит на карту - возврата VAT будет!\

**Фактуры, которые не будут приняты:**

* если фактура была оплачена с помощью **рассрочки** или другими способами с делением на раты по оплате - такие фактуры **НЕ принимаются,**
* фактура, где не указан номер автомобиля для которого была выполнена услуга,
* фактура, где не указан способ оплаты (и не предоставлено подтверждение оплаты нам в чат),
* фактура, с указанием неверных данных нашей фирмы,
* мы принимаем фактуры сроком не старше 3 месяцев. Например, фактуры за июль можно будет отправить только до октября.
* Фактуры добавленные через систему KSeF (государственная система электронных фактур):\
  \- должен быть указан ID клиента + номер авто(если заправка)<br>
