# Регистрация аккаунта

## Регистрация аккаунта Bolt производится отделом регистрации, при условии, что все условия по нашей стороне выполнены&#x20;

_**Какие условия должны быть выполнены для того, чтобы мы произвели регистрацию аккаунта Bolt Taxi?**_&#x20;

1. Подача на идентификатор/сглошение от нас
2. Подача на разрешение на работу/подписанный трудовой договор&#x20;
3. Подписанный договор аренды транспортного средства  (Umowa Wynajmu)
4. Оклеенное авто для работы с выписом от нас

* [x] После успешной регистрации аккаунта Bolt, водитель получает сообщения на электронную почту/номер телефона с ссылкой для установления пароля
* [x] Создав пароль, водитель может войти в аккаунт, но при этом, войти в сеть и приступить к работе сможет только после посещения офиса для верификации личности
* [x] Записаться в офис водитель может самостоятельно, либо же попросить сделать это нас и мы запишем на удобное для него время \
  Ссылка для записи на верификацию - [https://app.acuityscheduling.com/schedule/b02a6806](https://app.acuityscheduling.com/schedule/b02a6806)\
  \*Если человек в офисе это делаем - мы, если чат, то отправляем черновик в отдел регистрации

_**Пройдя верификацию в офисе Bolt, аккаунт будет активен в течении 48 часов с момента пройденной верификации, согласно регламенту, но обычно активация производится быстрее!**_
