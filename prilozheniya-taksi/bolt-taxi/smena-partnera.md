# Смена партнера

**Смена партера в Bolt производиться путем перерегистрации аккаунта**&#x20;

_**ВАЖНО: для перерегистрации аккаунта необходимо использовать электронную почту, которая ранее не использовалась для Bolt (BoltFood, клиентское приложение для заказа такси/еды, аккаунты в других странах)**_ &#x20;

_При этом статистика в аккаунте Bolt водителя после смены партнера будет обнулена на время, но через пару дней снова будет возвращена._&#x20;

_**Документы, необходимые для перерегистрации аккаунта**_

* Загранпаспорт или карта побыта, никакой другой документ принят не будет
* Польское водительское удостоверение (обязательно должны биться в системе [CEPIK](https://moj.gov.pl/uslugi/engine/ng/index?xFormsAppName=UprawnieniaKierowcow\&xFormsOrigin=EXTERNAL))
* Селфи&#x20;
* Польская справка о несудимости не старше 30 дней с момента выдачи
* Медицинская справка (orzeczenie lekarskie art.43)
* Справка от психолога (orzeczenie psychologiczne art.39)
* Идентификатор водителя ( или подтверждение о подаче не старше 90 дней)&#x20;

**Данные для аккаунта:**

* Электронная почта (которая ранее не использовалась)
* Польский номер телефона\
  \
  Активация аккаунта занимает до 3 рабочих дней - по регламенту, но обычно быстрее.
