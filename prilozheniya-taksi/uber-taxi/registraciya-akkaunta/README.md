# Регистрация аккаунта

* [x] Установить приложение Uber Driver
* [x] Ввести номер телефона и электронную почту
* [x] Ввести пригласительный код (он меняется - куратор уведомляет об этом) + курьер может ввести код друга. Ввод кода необязателен и пункт можно просто пропустить.
* [x] Выбрать вариант партнерства с Uber - Выполнять поездки с Uber с лицензией на вождение такси владельца автопарка.
* [x] Отметить наличие польских прав
* [x] Загрузить необходимые документы:

- Удостоверение личности (загранпаспорт/карта побыта)
- Польское водительское удостоверение&#x20;
- Свидетельство о несудимости (не старше 30 дней)

* [x] Заполнение важных пунктов и запись на верификацию

- Найти владельца автопарка - выбрать пункт "Я уже состою в автопарке"
- Личная встреча для проверки документов
- С чего начать (условия работы с приложением)

**После заполненных пунктов водитель должен посетить пункт верификации Uber, активация после верификации занимает до 72 часов. Как только человека пропустит на карту города - можно начинать подключение.**&#x20;
