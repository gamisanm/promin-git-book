# 📖 Кадры

Наша система трудоустройства базируется на двух типах договоров: Umowa Wynajmu (основной заработок) и Umowa Zlecenia (выплаты зависят от ставки). &#x20;

Такой подход связан с нестабильностью заработка водителей или курьеров. Мы распределяем выплаты так, чтобы они соответствовали требованиям законодательства. &#x20;

**Umowa Zlecenia** включает налог ZUS, обеспечивающий социальные гарантии: медицинская страховка, что полностью соответствует закону. \
\
**Umowa Wynajmu** применяется для оставшейся части дохода. Оба договора полностью соответствуют юридическим нормам Польши и одобрены специалистами. &#x20;

Студенты до 26 лет освобождены от уплаты ZUS, если они работают по Umowa Zlecenia.

**Umowa Zlecenia не является обязательным документом для подписания при работе курьером**
