# 🛵 Glovo Rider

{% hint style="info" %}
**Glovo – это популярное приложение для доставки еды, товаров и посылок. Курьеры могут работать на велосипеде, скутере или автомобиле, выбирая удобный график.**
{% endhint %}

&#x20;Заработок зависит от **города, времени работы и количества заказов**. В среднем:

* **25-40 zł/час** – при высокой активности.
* **4 000 – 8 000 zł/месяц** – если работать полный день в большом городе.
* **Доплаты** за пики спроса, вечерние смены, дождливую погоду.
* **Чаевые** могут значительно увеличить доход.
