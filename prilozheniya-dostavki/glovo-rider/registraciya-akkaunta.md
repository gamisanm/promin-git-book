# Регистрация аккаунта

Регистрацию Glovo аккаунта лучше производить со стороны партнера, но есть ситуации, когда курьеры проводят регистрацию самостоятельно. Разберем оба момента:

* **Регистрация с нашей стороны (занимается отдел регистрации).**

> Для отправки черновика в регистрации нам потребуется следующие данные:
>
> * Электронная почта, которая ранее не использовалась в Glovo, даже пользовательском.
> * Польский номер телефона&#x20;
> * Селфи курьера без очков, кепки и подобных лишних предметов
> * Паспорт или карта побыта
> * Фото лица с паспортом или картой в руках. Документ который будет в руках зависит от того, какой документ будет выслан для регистрации.
> * Информация о типе транспорта
> * Информация о наличии сумки для работы курьером

{% hint style="info" %}
<mark style="color:red;">**Важно уточнять у человека имел ли он аккаунт ранее либо может пробовал проходить регистрацию, так как если вдруг его документы уже есть в системе Glovo, то при регистрации нами - аккаунт не активируют**</mark> &#x20;
{% endhint %}
