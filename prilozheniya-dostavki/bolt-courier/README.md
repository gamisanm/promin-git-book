**Города** в которых есть возможность работать курьером **в Bolt Couri**er:

**Заработок зависит от города, количества доставок и смен. В среднем:**

| Город   | Средний доход в месяц\* | Заказов в день | Примерная ставка за заказ |
| ------- | ----------------------- | -------------- | ------------------------- |
| Варшава | 4000–7000 zł            | 10–20          | 10–18 zł                  |
| Краков  | 3500–6000 zł            | 8–15           | 9–17 zł                   |
| Вроцлав | 3500–6000 zł            | 8–15           | 9–17 zł                   |
| Познань | 3000–5500 zł            | 7–14           | 8–15 zł                   |
| Гданьск | 3000–5000 zł            | 6–12           | 8–14 zł                   |
| Лодзь   | 2800–5000 zł            | 6–12           | 8–14 zł                   |

**Дополнительно:**

* Можно зарабатывать **больше**, если работать в часы пик, в плохую погоду и участвовать в бонусных программах.
* Некоторые курьеры получают **7000–8000 zł+**, если работают 6–7 дней в неделю по 10–12 часов.
