# 🛵 Wolt Courier

Города в которых есть возможность работы в Wolt Courier:

<figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure>

Заработок зависит от города, количества выполненных заказов, времени работы и погодных условий. Ниже приведены средние показатели:

| Город/Регион                 | Средний доход в час (брутто) | Средний доход за заказ (брутто) |
| ---------------------------- | ---------------------------- | ------------------------------- |
| Варшава                      | 25–34 zł                     | 15,60 zł                        |
| Краков (Малопольское)        | до 40 zł                     | —                               |
| Вроцлав, Гданьск, Трёхградье | 30–36 zł                     | —                               |
| Щецин                        | \~27,90 zł                   | —                               |
| Среднее по Польше            | 34,41 zł                     | 15,41 zł                        |

* Работа в Wolt не требует фиксированного графика
* Оплата производится ежедневно или еженедельно
* Дополнительные бонусы возможны за работу в часы пик, в плохую погоду или по выходным.
