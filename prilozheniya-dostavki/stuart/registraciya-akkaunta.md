# Регистрация аккаунта

Регистрация происходит через отдел регистрации, от курьера нам нужно:

* Адрес электронной почты
* Номер телефона
* Город работы
* Телефон с функцией NFC (Iphone/Android)
* Фото загранпаспорта

**Активация аккаунта в течении недели.**&#x20;

**Stuart** - приложение для работы

**Viva.com** - приложение для приема оплаты от клиентов
