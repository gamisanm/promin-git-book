# Пригороды

**Можно ли подать только автомобиль, а себя нет?** \
\
На пригороды должен быть подан водитель и автомобиль, только авто подать нельзя. У каждого пригорода имеется «виртуальный идентификатор» - сглошение водителя. Такие пригороды, как Nowy Dwór Mazowiecki и Łomianki имеют физические идентификаторы.  \
\
**Umowa Użyczenia и для чего она нужна?** \
\
Чтобы подать автомобиль на получение выписа для пригородов нужно подписать документ «Umowa Użyczeniа». Это документ, подтверждающий то, что владелец разрешает автомобилю ездить в такси от нашей фирмы в пригороде, на который хочет подаваться. Документ требуется в каждом пригороде и должен быть подписан ВЛАДЕЛЬЦЕМ автомобиля по техпаспорту. Без него подача автомобиля на пригороды невозможна.  Можно ли подать автомобиль с временным тех паспортом и техосмотром такси? К сожалению, нет. Подача автомобиля осуществляется только с постоянным техпаспортом и печатью TAXI поставленным в нем.  

{% hint style="info" %}
**Каждый пригород имеет разные правила принятия документов и все они немного отличаются. Поэтому мы настоятельно просим водителей перед подготовкой документов приходить в офис на консультацию.**
{% endhint %}
