# 📄 Легализация

**Отдел легализации выполняет следующие основные функции:**

1\. Подача водителей на получение идентификаторов

* Сбор и проверка документов, необходимых для подачи.
* Мониторинг процесса рассмотрения подач водителей и их своевременное информирование о статусе готовности идентификатора.
* Подготовка ответов на запросы ужондов и предоставление дополнительной информации по мере необходимости.

2\. Взаимодействие с ужондами

* Поддержание контактов с работниками ужондов для эффективного и оперативного решения вопросов, связанных с получением идентификаторов и выписов.
* Разработка улучшений по взаимодействию с ужондами для ускорение процесса выдачи документов (идентификатора и выписа).

3\. Подача автомобилей на получение выписов из лицензии

* Подготовка необходимого пакета документов для подачи вашего автомобиля на получение выписа из лицензии.
* Контроль за их готовностью и выдачей в ужонде.

4\. Информационная поддержка водителей

* Консультации водителей по вопросам получения идентификаторов и выписов из лицензий.
* Консультация водителей об основных требованиях законодательства, касающимся их легальной деятельности в такси.
* Помощь в решении проблемы водителя лично в офисе, а также в телефонном режиме.
